## Week 5 topics

1. Week 5 introduction — the transition into the actual OOA process
2. What is Object-Oriented Analysis?
3. The key question: what important things exist in the problem domain?
4. Object vs class (car and student analogies)
5. UML class notation — name, attributes, operations
6. Attributes vs operations (information vs behaviour)
7. Object notation (underlined name, attribute values)
8. The object modelling process
9. Identifying candidate classes — the noun technique, with a warning
10. Links and associations (class level vs object level)
11. Naming an association and roles
12. Multiplicity and common multiplicities
13. One-to-one, one-to-many, many-to-many
14. Generalization and specialization (is-a)
15. Generalization vs association
16. The is-a and has-a tests
17. A complete class example (User · Student · Lecturer)
18. CASE tools — assist modelling, never replace analysis
19. Practical lab, validation checklist, common mistakes
20. Key terms, big picture, examination-style question, references
