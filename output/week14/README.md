## Week 14 topics

1. Object-oriented design — definition; analysis vs design; analysis → design transformation
2. The three major models (object, dynamic, behavioural); why all three are needed
3. One system, multiple views (six UML views)
4. From use case to design — basic flow and candidate classes
5. Responsibility assignment (knowing vs doing)
6. Design classes; visibility (+, −, #, ~); attributes and operations
7. Sequence diagrams → class operations; model consistency
8. Object + dynamic model; object + activity model (responsibility mapping)
9. Use-case model, traceability; controller, service and domain knowledge
10. Design refinement; designing for change; design patterns (Strategy)
11. Integrated case study; model validation; design-quality checklist
12. Common mistakes; tutorial, practical and exam questions; references
