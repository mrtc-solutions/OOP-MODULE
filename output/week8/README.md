## Week 8 topics

1. Behavioural modelling — definition and why it is needed; the modelling family
2. Use cases — goals, not functions; actors (human and non-human)
3. Use case diagrams — notation, system boundary, complete example
4. Use case relationships — association, include, extend, generalisation
5. Use case specifications — main scenario, alternative and exception flows
6. Interaction diagrams and sequence diagrams — lifelines, activation bars, messages
7. Combined fragments — alt, loop, opt
8. Communication (collaboration) diagrams and sequence-vs-communication
9. Activity diagrams — notation, decisions, forks/joins, swimlanes
10. How the models work together (use case → activity → sequence) and traceability
11. Full analysis documentation
12. Practical lab, tutorial, common confusions, exam questions, references
