## Week 13 topics

1. Software architecture — meaning; architecture vs class design
2. Multilayer architecture — layers and the basic four-layer + database structure
3. The Presentation, Application, Domain and Data Access layers
4. Separation of concerns; cohesion and coupling
5. Software components — component vs class; component interfaces
6. Reusable components and adaptable components; reuse vs inheritance (composition)
7. UML component diagrams; packages and package vs component
8. Dependencies and dependency direction
9. Benefits and limitations of multilayer architecture
10. Reuse and adaptability case studies; the component-diagram exercise
11. Practical UML notation; deployment thinking (logical vs deployment)
12. Reusability design principles; tutorial, practical and exam questions; references
