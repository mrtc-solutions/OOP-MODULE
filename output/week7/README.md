## Week 7 topics

1. What dynamic modelling means — structural vs dynamic (what exists vs what happens)
2. The car analogy
3. Events — definition, categories (user, system, external, data) and examples
4. Events vs states; events and transitions
5. States, the Order lifecycle, UML state-machine notation (initial/final states)
6. Transitions and guards (ATM withdrawal)
7. Entry, exit and do behaviour; the payment state machine
8. Operations — operation vs event, operations causing state change
9. Concurrency — sequential vs concurrent, airport, UML concurrent regions
10. Relationship between structural and dynamic models; models revealing problems
11. CASE tool support for dynamic models
12. Hospital appointment complete example; state vs class vs object
13. State machine vs flowchart; the traffic light
14. Practical lab, tutorial, common mistakes, exam questions, references
